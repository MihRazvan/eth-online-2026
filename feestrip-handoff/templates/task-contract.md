# Bounded task contract template

Use only fields that help this assignment. Replace the descriptive entries with actual facts; this is not an executable plan.

- **Objective:** one concrete outcome.
- **Owner/reviewer:** actual assigned agents or roles.
- **Base:** commit SHA and verified worktree path.
- **Read:** relevant product clauses, source pins and interface definitions.
- **Own:** exact files/modules; separately identify forbidden/shared files.
- **Inputs/dependencies:** agreed ABI/data shapes and available services.
- **Acceptance:** observable result, adversarial case and independent oracle where relevant.
- **Evidence:** commands, scope, commit, durable artifacts and limitations.
- **Return:** changed files, result, findings, conflicts and next action.

Escalate a material product contradiction with concrete evidence. Continue useful independent work; do not change the agreed interface or economics silently.
