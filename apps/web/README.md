# FeeStrip web application

React/Vite/TypeScript. Run from repository root after the lead-managed dependency install:

```sh
pnpm --filter @feestrip/web dev
pnpm --filter @feestrip/web build
pnpm --filter @feestrip/web test
```

The default `main.tsx` passes an explicit `FixtureAdapter` to the exported `App`. Every amount and transaction in this mode is visibly a deterministic fixture; it never requests signatures or invents transaction hashes. Tests cover UI behavior, not a production wallet signing interface or live protocol acceptance.

`types.ts` exports the integration boundary. All claim quantities (supply, inventory, holdings, action amounts) use 18-decimal integer base units. USDC balances/prices use 6-decimal integer base units; `askMicros` is USDC per one whole claim. The earning endpoint is a block, while offer/quote expiration fields are timestamps. `amounts.ts` parses user input and rounds purchase cost upward to the next USDC base unit. Payout presentation floors the original-Q proportion.

The lead owns the viem chain adapter and shared ABI. It supplies `load`, `connect`, `execute`, optional `switchNetwork`. `execute` must validate current chain state, wait for a real receipt, and return only a genuine transaction hash. The UI reloads after execution. Historical Graph data is not a settlement authority. The live adapter must not expose fixture controls or silently fall back to fixtures.

Design source, immutable concept captures, independent critique, reference notes and browser evidence are in `docs/design/`. Self-hosted DM Sans and Manrope include their SIL Open Font Licenses. All application code and design artifacts in this increment were generated by Codex, reviewed by the integration lead; no human design review is claimed.
