PRIVACY

last changed 13 sep 2026

The short version: we collect nothing, store nothing, and have nothing to sell. There is no account, no email field, no cookie, no tracking pixel and no analytics script anywhere on this site.

WHAT WE COLLECT

Nothing. That is the entire list. There is no server holding your data because there is no server holding data at all — the interface is a static page that talks directly to the blockchain through your own wallet.

WHAT WE DON’T DO

  • No cookies, no local profiling, no fingerprinting
  • No analytics, heatmaps, session recording or A/B tooling
  • No advertising, no data brokers, no “partners”
  • No newsletter list, because there is no newsletter
  • No linking of wallet addresses to identities, ever

THE ONE THING STORED

If you dismiss the privacy note at the bottom of the page, a single flag is written to your browser’s local storage so the note stays dismissed. It never leaves your machine and we cannot read it. Clear your site data and it is gone.

WHAT WE CAN’T CONTROL, AND WON’T PRETEND TO

Being honest matters more here than sounding clean:

  • Your wallet provider sees which sites you connect to. That is between you and them.
  • Your RPC endpoint sees the requests it serves, including your address. Run your own node if that matters to you.
  • Our host serves this page and, like every web host, its edge may briefly log IP addresses for abuse prevention. We do not read those logs, query them or export them.
  • Everything you do on-chain is public by design. That is the chain, not us.

IF THAT EVER CHANGES

If we ever add anything — even a cookieless visit counter — it gets written here first, in plain words, with the date changed at the top. We will not quietly expand this page and hope nobody re-reads it.

ASKING US THINGS

There is no data to request, correct or delete, so there is no request form. If you want to check any of the above, the entire frontend is open source and you can read it yourself.
