# usufruct

[Watch the demo](https://youtu.be/VBQnQqMLmTY) · [Current integration details](docs/submission.md)

The deck includes earlier development benchmarks; the current Studio version is **v0.2.0**, and the public allocation used **4,396,570 gas**. [Live verification](docs/VERIFICATION.md).

For the precise flow: publishing a listing moves no assets. Seller acceptance of a funded offer transfers the NFT into escrow and pays the seller. The same NFT can return after capture, before proof allocation or claim redemption. Historical verification authenticates PoolManager state. The problem statements describe the target use case, not the absence of competing lending or fee-trading products. [Protocol specification](docs/SPECIFICATION.md).
